# Customer Churn Prediction

## Project Overview

This project predicts customers who are likely to discontinue a service using machine learning.

## Dataset

IBM Telco Customer Churn Dataset.

## Work Performed

- Data cleaning and preprocessing
- Exploratory Data Analysis
- Feature engineering
- One-hot encoding
- Train-test split
- Logistic Regression
- Random Forest
- XGBoost
- Confusion Matrix
- ROC Curve
- Feature Importance

## Model Evaluation

| Model | Accuracy | Recall | ROC-AUC |
|---|---:|---:|---:|
| Logistic Regression | 80.48% | 56.42% | 84.31% |
| Random Forest | 78.85% | 48.93% | 81.80% |
| XGBoost | 80.55% | 52.67% | 84.38% |
